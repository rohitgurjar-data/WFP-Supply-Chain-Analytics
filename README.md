# 🌍 World Food Programme (WFP) Supply Chain Analytics Dashboard

## 📌 Project Overview

This project analyzes the global humanitarian supply chain operations of the World Food Programme (WFP) between **2006 and 2015**.

The objective is to identify shipment trends, country performance, vendor efficiency, logistics costs, delivery performance, and product distribution using interactive Power BI dashboards.

The project demonstrates an end-to-end Data Analytics workflow including:

- Data Cleaning (Excel)
- Data Analysis (SQL)
- Data Visualization (Power BI)
- Business Insights
- Dashboard Design

---

# 🎯 Business Problem

Efficient humanitarian logistics is critical for delivering food and medical supplies worldwide.

This project answers important business questions such as:

- Which countries receive the highest shipment value?
- Which vendors contribute the most shipments?
- Which shipment modes are most frequently used?
- What is the average delivery time?
- Which countries have delayed deliveries?
- How are freight and insurance costs distributed?
- How does shipment weight affect logistics cost?

# 📌 Key Business Insights

- Zambia recorded the highest shipment value.
- Nigeria contributed the largest overall shipment value among recipient countries.
- SCMS from RDC was the leading vendor.
- Air transport handled the largest share of shipments.
- Freight cost represented a significant portion of logistics expenditure.
- Delivery performance varied considerably across countries.
